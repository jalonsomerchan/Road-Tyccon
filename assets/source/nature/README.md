# Árboles y montañas

`nature-atlas-raw.png` contiene los ocho objetos generados en una cuadrícula 4x2. Los sprites transparentes finales están en `assets/sprites/nature/` y se cargan en el atlas compartido de `scripts/visuals.gd`.

`terrain_chunk.gd` elige árboles para casillas de bosque y montañas para casillas de montaña. El mapa del menú usa las mismas familias. Las imágenes originales se conservan aquí para poder regenerar o reemplazar las variantes.
